# AURELLE — Timeless Jewellery

AURELLE is a modern jewellery e-commerce storefront designed around elegance, simplicity and a seamless shopping experience. It features a curated jewellery collection with product browsing, category filtering and a shopping bag.

**Live Demo:** https://aurelle-store-gamma.vercel.app/

## Preview

Explore the live application: [AURELLE](https://aurelle-store-gamma.vercel.app/)

## Features

- **Premium storefront:** Minimal, elegant design inspired by modern jewellery brands.
- **Product catalogue:** Browse necklaces, rings, earrings and bracelets.
- **Category filtering:** Filter products by jewellery category.
- **Product search:** Find products using the search field.
- **Shopping bag:** Add products to your shopping bag.
- **Responsive design:** Layout designed for different screen sizes.
- **SEO foundations:** Page metadata and search-friendly page structure.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pr7212/aurelle-store.git
   ```

2. Navigate into the project:

   ```bash
   cd aurelle-store
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser at:

   ```text
   http://localhost:3000
   ```

## Design Direction

AURELLE uses a clean visual identity, refined typography, neutral tones and carefully selected jewellery imagery to create a premium shopping experience.

The goal was to build a storefront that feels elegant, intuitive and easy to navigate.
